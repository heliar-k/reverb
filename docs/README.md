# docs/ 目录结构

根目录只放本文件，其余文档按类型归入子目录：

| 目录 | 放什么 |
|------|--------|
| `guide/` | 面向使用者的概念、选型、避坑指南 |
| `design/` | 设计文档（动机、方案权衡、架构决策） |
| `spec/` | 实现规格（文件结构、类声明、可直接开发的细节） |
| `research/` | 外部事实考证、调研笔记 |
| `benchmark/` | 性能基线与测量报告 |
| `adr/` | 架构决策记录（不可变，推翻旧决策就新开一份） |
| `ticket/` | 已结案 ticket 归档，索引见 `ticket/README.md` |
| `images/` | 文档引用的图片 |

规则：

- 新文档**必须**进上表某个子目录；pre-commit 会拦住直接放在 `docs/` 根目录的 md 文件。
- 文档之间互相链接用相对路径（如 `../design/numpy-shm-design.md`）。
- 一份文档只归一类；不确定时看文档回答的问题——「怎么用」进 `guide/`，「为什么这么设计」进 `design/`，「照着做」进 `spec/`。
